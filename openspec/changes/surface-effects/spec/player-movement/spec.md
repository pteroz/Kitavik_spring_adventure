## ADDED Requirements

### Requirement: Замедление на соломе
При движении по тайлу со свойством `surface=straw` максимальная горизонтальная скорость должна быть снижена в 1.5 раза относительно обычной для того же режима (тап, ходьба, бег).

#### Scenario: Ходьба по соломе
- **WHEN** игрок идёт по тайлу со свойством `surface=straw`
- **THEN** скорость ходьбы составляет примерно 2/3 обычной

#### Scenario: Бег по соломе
- **WHEN** игрок бежит по соломе
- **THEN** максимальная скорость бега также снижена в 1.5 раза
