# Специальные платформы (special-platforms) — дельта спецификации

## ADDED Requirements

### Requirement: Соскакивание с односторонней платформы
Игрок должен уметь намеренно соскочить вниз сквозь одностороннюю платформу по нажатию «вниз», стоя на ней.

#### Scenario: Соскок вниз
- **WHEN** игрок стоит на односторонней платформе и нажимает «вниз» (S/↓)
- **THEN** игрок проходит сквозь платформу вниз
- **AND** через короткое время (0.18 c) платформа снова начинает удерживать игрока
