# Враги (enemies) — спецификация

## Purpose

Наземные враги патрулируют заданную область, подпрыгивают при упоре в препятствие и опасны при касании: столкновение с врагом отправляет игрока на точку возрождения. Поведение врага задётся свойствами из карты (сила движения, радиус патруля, тип).

## Requirements

### Requirement: Патрулирование вокруг точки старта
Враг должен двигаться туда-обратно вокруг точки своего размещения в пределах радиуса патрулирования.

#### Scenario: Движение в пределах патруля
- **WHEN** враг активен
- **THEN** он перемещается горизонтально с заданной силой движения
- **AND** разворачивается, когда достигает границы радиуса патрулирования от точки старта

#### Scenario: Радиус по умолчанию
- **WHEN** у врага не задан собственный радиус патрулирования
- **THEN** применяется значение по умолчанию 96 px

### Requirement: Подпрыгивание при упоре
Если враг на земле и его горизонтальная скорость падает ниже порога (упёрся в препятствие), он должен подпрыгнуть, чтобы продолжить патруль.

#### Scenario: Упор в стену
- **WHEN** враг на земле и его горизонтальная скорость меньше 10 px/с
- **THEN** враг получает вертикальный импульс вверх (подпрыгивает)

### Requirement: Анимация ходьбы
Враг должен проигрывать циклическую анимацию ходьбы из кадров спрайт-листа, развёрнутую в сторону движения.

#### Scenario: Кадры походки
- **WHEN** враг движется
- **THEN** его спрайт переключает кадры походки с интервалом 0.1 c
- **AND** кадр развёрнут в сторону текущего направления

### Requirement: Опасность при касании
Столкновение игрока с врагом должно возвращать игрока на точку возрождения уровня (враг при этом не уничтожается).

#### Scenario: Касание врага
- **WHEN** игрок сталкивается с врагом
- **THEN** игрок перемещается на точку возрождения с нулевой скоростью
- **AND** враг остаётся на уровне
