# Загрузка уровня (level-loading) — спецификация

## Purpose

Уровень — это данные (Tiled-карта), а не код: игра загружает `.tmx` по номеру уровня, строит мир из слоёв, размещает игрока и врагов из объектных слоёв, а свойства тайлов определяют типы платформ. Отсутствие карты не должно ронять игру.

## Requirements

### Requirement: Загрузка карты по номеру уровня
Система должна загружать карту уровня `level{N}.tmx` и строить из неё игровую сцену.

#### Scenario: Существующая карта
- **WHEN** запускается уровень N и файл `level{N}.tmx` существует
- **THEN** карта загружается и её слои становятся игровыми объектами

### Requirement: Слои карты
Система должна различать слои: обычные платформы, односторонние платформы, движущиеся платформы, монеты, передний план (параллакс), фон и фоновое изображение.

#### Scenario: Распознавание слоёв
- **WHEN** карта содержит слои платформ, односторонних/движущихся платформ, монет и фоновые слои
- **THEN** каждый слой обрабатывается по своему назначению

### Requirement: Точка появления игрока
Игрок должен появляться в точке, заданной объектным слоем спавна; при её отсутствии — в запасной позиции по умолчанию.

#### Scenario: Спавн из карты
- **WHEN** на карте задана точка спавна
- **THEN** игрок появляется в этой точке

### Requirement: Размещение врагов из карты
Враги должны размещаться по объектам соответствующего слоя с их координатами и свойствами (сила движения, радиус патруля, тип по имени объекта).

#### Scenario: Враг с параметрами
- **WHEN** объект врага имеет собственные силу движения и радиус патрулирования
- **THEN** враг создаётся с этими параметрами

#### Scenario: Неизвестный тип
- **WHEN** имя объекта задаёт нереализованный тип врага
- **THEN** создаётся враг базового типа (с предупреждением)

### Requirement: Тип платформы из свойств тайла
Свойства тайла должны определять тип платформы: обычная, скользкая, хрупкая или разбиваемая.

#### Scenario: Скользкий тайл
- **WHEN** тайл платформы помечен как скользкий
- **THEN** платформа ведёт себя как скользкая (пониженное трение)

### Requirement: Запасной уровень без карты
Если файл карты отсутствует, система должна построить простой запасной уровень и продолжить игру без сбоя.

#### Scenario: Карта не найдена
- **WHEN** `level{N}.tmx` не найден
- **THEN** создаётся запасной уровень (пол, несколько платформ, монеты) и игра запускается
